CarbonSpace Sync

by Unknown Works

Send the areas and volumes from a Revit schedule straight into a CarbonSpace calculation. No typing them in by hand.

1Install (once, about 30 seconds)

  1. Show your bookmarks bar in Chrome or Edge: press Ctrl + Shift + B.
  2. Drag this green button onto the bookmarks bar:
    CarbonSpace Sync

If dragging doesn't work: , then right-click the bookmarks bar → Add page…, name it CarbonSpace Sync, and paste the code into the URL field.

The bookmark always loads the latest version of the tool, so you only install it once.

2In Revit: export the schedule

  • Your schedule needs the columns Family and Type and Area / Volume (Count is optional).
  • Export it: File → Export → Reports → Schedule, and keep the default .txt format.
  • Optional: add a CS_ComponentId type parameter. When it is filled in, that number always wins. You can also leave it out and match types in the panel instead (see step 3).

The tool uses whichever measure the component is made for: Area for components per m², Volume for per m³, Count for per piece. You don't need to choose.

3Push to CarbonSpace

  1. Log in at public.carbonspace.earth and open the calculation you want to update.
  2. Click CarbonSpace Sync in your bookmarks bar. A panel opens on the right.
  3. Drag your exported schedule(s) into the panel. You can drop walls, roofs and floors together.
  4. Match types: each Revit type has a dropdown of CarbonSpace components (UW Library and this project).
    • Components from: pick the project's folder, e.g. UW Library / UW Components / Project A. Suggestions only come from that folder, so another project's WT.01a is never picked. A folder named like the CarbonSpace project is chosen automatically. Otherwise the panel remembers your last choice for that project.
    • The best matches by name are at the top (•). The tool reads type codes, so uw01 300mm, UW-01 ext and UW.01 all match the component UW.01.
    • When exactly one component matches, it is picked for you (name match).
    • You only choose once. The calculation remembers each type after the push (last push), and so does your browser (saved). Next time, the new export is matched automatically, even if you renamed the type slightly.
    • Pick — none (skip) — for types that should not count.
  5. Check What will change, then click Push to CarbonSpace. Finally, click Reload to see the new result.

Need the numbers in Revit too? Click download this schedule with CS_ComponentId filled in above the type table. You get the same file with the numbers added, to copy into the Revit parameter.

In the previewMeaning
UPDATEThe component is already in the calculation. Its quantity changes to the Revit value.
CREATENew in this calculation. It is added to a group chosen from the schedule name (Wall → Facade opaque, Roof → Roofs …).
KEEPNothing changed since the last push.
STALEAdded by an earlier push, but no longer in Revit. Tick the box at the bottom to remove it.
  • Anything typed in by hand in CarbonSpace (foundations, services …) is never changed or deleted.
  • Types without a CS_ComponentId are listed in orange and skipped.
  • Before every push, the panel downloads a backup of the calculation (a .json file in your Downloads).
  • It uses your own CarbonSpace login. You can only change projects you have write access to.

?Problems

  • Nothing happens when I click the bookmark: make sure you're on public.carbonspace.earth and logged in, then reload the page and try again.
  • "401": your CarbonSpace session expired. Log out, log in again, and retry.
  • "does not exist or you have no access": the number in CS_ComponentId is wrong.
  • "is measured in kg": that component is per kg, which a schedule can't provide. Use a per m² or per m³ component instead.
